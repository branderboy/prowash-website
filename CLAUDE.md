# ProWash Website — Project Rules

## Booking Rules

| Service | How to Book |
|---|---|
| Window Tinting | **Call to book** — (301) 307-1414 |
| Car Detailing | **Book online** via Acuity Scheduling embed on `book.html` |
| Car Wash | **Walk-in only** — no appointment needed |

The `book.html` page uses a 3-button service selector to enforce these rules:
- Tinting button → shows call prompt (301) 307-1414
- Detailing button → shows Acuity embed with location tabs
- Car Wash button → shows walk-in message with link to locations

The hero CTA "Book Detailing Appt. Now!" on `index.html` links to `book.html`.
